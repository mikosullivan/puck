The Kiera distributed object system

Kiera is a distributed object system built around a cryptographically signed blockchain. Objects are identified by UNS (Universal Namespace) addresses in the form domain/path. This site publishes the namespaces owned and maintained by kiera.uno.

Namespaces

  • kiera.uno/object — base object type for the Kiera distributed object system
  • kiera.uno/primitive — primitive value types (string, number, boolean, null, hash, array)
  • kiera.uno/class — base class type for Kiera objects
  • kiera.uno/software — software and programming language identifiers
  • kiera.uno/tag — searchable tag namespace
