puck.uno/primitive/hash

Key-value map

An ordered collection of key-value pairs. Keys are strings; values may be any primitive or object. The empty hash {} is a valid value.

Hashes are order-sensitive in the Puck ecoverse. The insertion order of keys is preserved and considered significant. Two hashes with the same keys and values but different key order are not equivalent.
