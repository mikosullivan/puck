kiera.uno/primitive

Primitive value types

The kiera.uno/primitive namespace defines the built-in primitive value types of the Kiera object system. Primitives are the atomic building blocks from which all Kiera objects are composed.

Primitives

  • kiera.uno/primitive/string — UTF-8 text value
  • kiera.uno/primitive/number — numeric value (integer or float)
  • kiera.uno/primitive/boolean — true or false
  • kiera.uno/primitive/null — absence of a value
  • kiera.uno/primitive/hash — key-value map
  • kiera.uno/primitive/array — ordered list of values
