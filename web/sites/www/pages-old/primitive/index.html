puck.uno/primitive

Primitive value types

The puck.uno/primitive namespace defines the built-in primitive value types of the Puck object system. Primitives are the atomic building blocks from which all Puck objects are composed.

Primitives

  • puck.uno/primitive/string — UTF-8 text value
  • puck.uno/primitive/number — numeric value (integer or float)
  • puck.uno/primitive/boolean — true or false
  • puck.uno/primitive/null — absence of a value
  • puck.uno/primitive/hash — key-value map
  • puck.uno/primitive/array — ordered list of values
