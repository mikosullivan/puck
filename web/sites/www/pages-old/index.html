The Puck distributed object system

Puck is a distributed object system built around a cryptographically signed blockchain. Objects are identified by UNS (Universal Namespace) addresses in the form domain/path. This site publishes the namespaces owned and maintained by puck.uno.

Namespaces

  • puck.uno/object — base object type for the Puck distributed object system
  • puck.uno/primitive — primitive value types (string, number, boolean, null, hash, array)
  • puck.uno/class — base class type for Puck objects
  • puck.uno/software — software and programming language identifiers
  • puck.uno/tag — searchable tag namespace
