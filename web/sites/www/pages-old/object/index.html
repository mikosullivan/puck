kiera.uno/object

Base object type for the Kiera distributed object system

The kiera.uno/object UNS identifies the root object type in the Kiera object system. All objects in Kiera are instances of this type. Objects are identified by UNS addresses in the form domain/path and are served over HTTPS by their domain owner.
