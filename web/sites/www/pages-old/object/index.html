puck.uno/object

Base object type for the Puck distributed object system

The puck.uno/object UNS identifies the root object type in the Puck object system. All objects in Puck are instances of this type. Objects are identified by UNS addresses in the form domain/path and are served over HTTPS by their domain owner.
