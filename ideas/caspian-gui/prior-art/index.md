Reference material for the [Caspian-GUI](https://www.puck.uno/ideas/caspian-gui/) brainstorm — what already exists in the visual-programming space, from kid-oriented block languages through professional dataflow tools. Plus the standard flowchart-symbol grammar (rhombus for decision, oval for start/end, etc.) that predates all of it.

Each subpage is one system: brief description, screenshot, and notes on what's worth stealing or avoiding for Caspian-GUI.

## Block-based educational

- [Scratch](https://www.puck.uno/ideas/caspian-gui/prior-art/scratch/) — MIT's iconic drag-and-snap block language for kids. *BSD 3-Clause (editor), free hosted service.*
- [Snap!](https://www.puck.uno/ideas/caspian-gui/prior-art/snap/) — Berkeley's Scratch successor with first-class procedures and lists. *AGPL v3.*
- [Blockly](https://www.puck.uno/ideas/caspian-gui/prior-art/blockly/) — Google's embeddable block-editor library that powers dozens of derivatives. *Apache 2.0.*

## Flow / dataflow

- [Node-RED](https://www.puck.uno/ideas/caspian-gui/prior-art/node-red/) — IBM's browser-based wiring editor for IoT flows. *Apache 2.0.*
- [LabVIEW](https://www.puck.uno/ideas/caspian-gui/prior-art/labview/) — the original graphical dataflow language, from National Instruments. *Proprietary (paid); free Community Edition for non-commercial use.*
- [Simulink](https://www.puck.uno/ideas/caspian-gui/prior-art/simulink/) — MATLAB's block-diagram companion for control systems and signal processing. *Proprietary (paid), no free tier.*

## Node graphs for creative work

- [Unreal Blueprints](https://www.puck.uno/ideas/caspian-gui/prior-art/unreal-blueprints/) — Unreal Engine's visual scripting for game logic. *Source-available under the Unreal Engine EULA; free until $1M per-product gross revenue, then 5% royalty.*
- [Grasshopper](https://www.puck.uno/ideas/caspian-gui/prior-art/grasshopper/) — parametric-design node graph inside Rhino 3D. *Bundled with Rhino (proprietary, paid); Rhino 6+ includes Grasshopper at no separate cost.*

## The grammar underneath

- [Flowchart symbols](https://www.puck.uno/ideas/caspian-gui/prior-art/flowchart-symbols/) — the ISO 5807 / ANSI shape vocabulary (rhombus, oval, parallelogram, cylinder, ...) that programming diagrams have used since before the visual-programming environments above existed.
