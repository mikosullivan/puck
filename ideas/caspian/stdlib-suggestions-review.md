**Ships** = the class ships with the Caspian binary (no fetch needed); `no` means it's a first-party class at `caspian.uno/*` resolved via `%fetch` on day 1. **Day 1** = accepted for V1 launch. Rejected rows get a hypothetical URL naming the class Caspian would have hosted if it were built. The **ghi** column opens a popup with a pre-filled GitHub issue form for that row.
