The **Xeme class** is the Caspian representation of a xeme at runtime — the object that test-tool code and post-test [`do`](../testing-tools/basic/#optional-do-block) blocks interact with. Its fields mirror the [Xeme JSON format](./); its methods let a program read and modify those fields programmatically.
