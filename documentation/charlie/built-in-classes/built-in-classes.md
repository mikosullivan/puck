Classes that are always available in Charlie without a require.

- **[Arrays](arrays.md)** — ordered collections.
- **[Bitwise](bitwise.md)** — bit-twiddling helpers on integers.
- **[Filesystem](filesystem.md)** — directory jails, file and
  directory objects.
- **[Hashes](hashes.md)** — order-preserving key/value collections.
- **[Meta-hash](meta-hash.md)** — the hash-of-hashes pattern.
- **[Nulls](nulls.md)** — `null`, null flavors, comparison.
- **[Numbers](numbers.md)** — integers and floats.
- **[Objects](object.md)** — the root object class.
- **[Strings](strings.md)** — single-quoted, double-quoted,
  heredocs, interpolation.
