# Kiera

Kiera is a foreign object API — a protocol for working with remote objects across different
languages and systems. Class names in Kiera use UNS strings (URLs without the `https://`
prefix), providing a globally unique namespace.

Mikobase will provide a Kiera-compatible interface. Much of what Mikobase defines — its
object model, class system, and query protocol — may be generalized into Kiera over time.

The details of the Kiera specification are outside the current scope. See
[marina.md](marina.md) for a prior design exploration.
